# X68 Control

A cleaner settings app for the Attack Shark X68 HE magnetic keyboard: actuation and Rapid Trigger, Snap Tap, DKS, tap-or-hold, toggles, remapping, lighting, macros and profiles.

**Download:** grab the latest `X68-Control-Setup-x.x.x.exe` from [Releases](../../releases/latest). The app updates itself after that.

Not affiliated with Attack Shark. Firmware updates still go through the official tool.
